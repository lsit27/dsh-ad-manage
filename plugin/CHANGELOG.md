# 版本更新日志（CHANGELOG）

本插件采用语义化版本 `主版本.次版本.修订号`（Major.Minor.Patch）。

## 1.0.0 — 2026-11-23

首个正式发布版本。

### 新增
- 域连接可视化配置：地址、端口、SSL/StartTLS、绑定 DN/密码、基准 DN、超时、分页大小，一键测试连接。
- 多套域配置管理与切换；敏感信息 AES-256-GCM 加密存储。
- 域用户全生命周期管理：新建、编辑、重置密码、启停、解锁、移动 OU、删除、查看所属组。
- 域计算机管理：新建、编辑、移动、删除、启停。
- 域组管理：安全组/分发组区分、成员增删、组成员清单。
- OU 树形导航与联动过滤；新建/重命名/移动/删除。
- GPO 读取、详情、启停、绑定/解绑（不编辑策略规则内容）。
- 全局检索、操作审计日志、RBAC 角色权限、高危操作二次确认。
- dsmarket 对接：搜索、详情、版本历史、兼容性校验、在线更新（更新前备份、失败回滚）、灰度渠道、授权校验、操作记录、下架后已装可用。
- LDAP/AD 双驱动（ldapjs + mock 演示驱动），分页查询，统一中文错误码。
