# AD/LDAP 域配置指引

## 0. 连接模式说明（重要）

插件有两类驱动：

- **真实 LDAP 模式**：已安装 `ldapjs` 且填入的域地址可达时，使用真实 LDAP/AD 连接。
- **内置演示模式（mock）**：用于没有真实域服务时的界面演示与联调。插件内置 3 用户 / 2 计算机 / 4 组 / 5 OU / 2 GPO 演示数据。

当前驱动选择逻辑：

| 场景 | 行为 |
|---|---|
| `LDAP_CLIENT_DRIVER=mock` | 强制演示模式 |
| `LDAP_CLIENT_DRIVER=ldapjs` | 强制真实模式，连接失败如实报错（不回退） |
| `auto`（默认） | 优先尝试真实 LDAP；连接失败或 `ldapjs` 缺失时**自动回退演示模式** |

「测试连接」会返回实际使用的驱动：若为演示模式，提示「演示模式连接成功（未连接真实目录服务）」。填入可达的真实域地址即自动使用真实连接。

> 要连接真实 AD/OpenLDAP，请确保 `ldapjs` 已安装（正式安装包会自动安装依赖），并填写真实、可达的服务地址与绑定凭据。

### 常见真实连接错误

| 错误提示 | 原因 | 处理 |
|---|---|---|
| 域服务器要求强认证（Strong Auth Required） | AD 禁止明文 LDAP 绑定 | 启用 SSL（LDAPS，端口 636）或 StartTLS，并确认证书可信 |
| 绑定 DN 或密码错误 | 凭据错误 | 核对绑定 DN（完整 DN）与密码 |
| 连接被拒绝 / 超时 | 地址不可达或端口错误 | 检查网络、防火墙与端口（LDAP 389 / LDAPS 636） |
| 超时（秒）设置过小 | UI 单位为秒 | 设为 10–30 秒 |

> 注意：插件**不会**在真实 LDAP 连接失败时静默切换到演示数据。若列表出现"张三/李四"等内置演示用户，说明当前处于演示模式（`LDAP_CLIENT_DRIVER=mock` 或未安装 ldapjs），而非连接到了真实域。

## 1. 新增域连接

进入「连接配置」页，点击「新建」，填写以下字段：

| 字段 | 说明 | 示例 | 校验 |
|---|---|---|---|
| 名称 | 便于识别的配置名 | 总部 AD 域 | 必填 |
| 服务地址 | 主域控 IP 或域名 | dc.example.com / 10.0.0.1 | 必填 |
| 备用域控 | 同一域的其它域控地址，多个用逗号分隔 | 10.0.0.2, dc02.example.com | 可选；主地址失败时依次尝试 |
| 端口 | LDAP 389 / LDAPS 636 | 389 | 1–65535 |
|  SSL | 使用 ldaps:// | 关 | 与 StartTLS 互斥 |
| StartTLS | LDAP 连接后升级 TLS | 关 | 与 SSL 互斥 |
| 绑定 DN | 管理员账号 DN | cn=admin,dc=example,dc=com | 建议最小权限 |
| 绑定密码 | 管理员密码 | — | 加密存储，输入时不回显 |
| 基准 DN | 搜索根目录 | dc=example,dc=com | 必填 |
| 连接超时(ms) | 单次操作超时 | 5000 | >0 |
| 分页大小 | 每页返回条数 | 100 | 1–1000 |
| 目录类型 | auto / ad / openldap | auto | — |

## 2. 测试连接

- 点击「测试连接」，插件会使用当前表单参数（含尚未保存的修改）建立连接并执行绑定。
- 成功：返回「连接并绑定成功」。
- 失败：返回明确中文原因，例如：
  - 连接被拒绝 → 检查地址与端口
  - 绑定失败 → 检查绑定 DN 与密码
  - 权限不足 → 绑定账号权限不够
  - TLS 握手失败 → 检查证书与加密配置
  - 分页超限 → 分页大小不得超过 1000

## 3. 多域管理

- 可保存多套域配置，在配置列表中切换「设为当前域」。
- 切换当前域后，所有对象列表自动切换到对应域；LDAP 客户端会重新连接。
- 可重置某套配置（清空敏感信息）或删除配置（需二次确认）。

## 4. AD 与 OpenLDAP 属性映射

插件统一处理两种目录的属性差异：

| 语义 | AD 属性 | OpenLDAP 属性 |
|---|---|---|
| 用户名 | sAMAccountName | uid |
| 用户主体名 | userPrincipalName | — |
| 显示名 | displayName | cn |
| 邮箱 | mail | mail |
| 手机 | mobile | mobile |
| 所属组 | memberOf | memberOf |
| 账户启用 | userAccountControl | userAccountControl |
| 锁定时间 | lockoutTime | — |
| 计算机 DNS 名 | dNSHostName | — |
| 操作系统 | operatingSystem | — |
| 组成员 | member | member / memberUid |

设置为 `auto` 时插件自动识别目录类型；也可显式指定。

## 5. 安全与加密

- 绑定密码使用 AES-256-GCM 加密，密文格式 `v1:iv:tag:data`，密钥不落明文。
- 密钥优先读取 `DSL_AD_LDAP_KEY`（base64 编码的 32 字节），否则在数据目录生成 `.key` 文件（权限 600）。
- 更换密钥会导致旧密文无法解密；更换前请先导出配置或备份 `.data` 目录。
- 插件不硬编码任何域地址、账号或密码，全部由 UI 录入。

## 6. 权限最小化建议

为绑定账号授予完成运维所需的最小权限即可：
- 只读审计：仅需读取权限（可用 `cn=readonly,...` 测试，插件会拒绝其写入操作）。
- 日常运维：用户/计算机/组的读写权限。
- 密码重置与删除：单独授予，且这些操作在 UI 需二次确认并记审计日志。
